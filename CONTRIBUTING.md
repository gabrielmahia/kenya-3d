# Contributing to kenya-3d

Thank you for your interest in improving civic data visualization for East Africa.

## How to Contribute

1. **Issues first** — open an Issue describing your proposed change before any PR.
2. **Scope** — new Blender visualization types, additional county/region data fetchers
   (Kenya, Tanzania, Uganda, Rwanda), prompt template improvements, docs.
3. **Out of scope** — license changes, non-civic-data use cases.

## Code Standards

- Python: formatted with `ruff`, type hints preferred
- Blender scripts: tested in Blender 4.x
- Every new visualization needs a prompt template in `prompts/`
