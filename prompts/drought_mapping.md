# Prompt: Drought Terrain Map

---

Use Blender MCP to create a Kenya drought terrain visualization:

1. Load `data/sample_drought.json`
2. Run `blender_scripts/drought_terrain.py` in Blender
3. Terrain displaced by drought severity — peaks = arid zones
4. Colour ramp: green (west, wetter) → deep red (northeast, arid)
5. Camera 52° from southwest for terrain drama
6. Sun from upper-left casting ridge shadows
7. Render and describe which areas have the highest peaks

Expected: Mandera/Wajir/Garissa corners are highest.
Central highlands (Nyeri, Kirinyaga) near-flat and green.
